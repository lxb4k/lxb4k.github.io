🔢 1. Числовые последовательности

Числовая последовательность — функция натурального аргумента:

x:N→R.

Каждому номеру n соответствует число xn​.

Пример из лекции

xn​=3n−12n+3​. Подставим первые натуральные числа: x1​=25​,x2​=57​,x3​=89​.

Выделяют монотонные, ограниченные и сходящиеся последовательности. Эти свойства могут сочетаться.

📈 2. Монотонность

Четыре вида монотонности

Для всех n∈N:

  • Возрастающая: xn+1​>xn​.
  • Убывающая: xn+1​<xn​.
  • Невозрастающая: xn+1​≤xn​.
  • Неубывающая: xn+1​≥xn​.
ВидУсловие при m>n
↗ Возрастающаяxm​>xn​
↘ Убывающаяxm​<xn​
📉 Невозрастающаяxm​≤xn​
📈 Неубывающаяxm​≥xn​

📏 3. Ограниченность

Последовательность называется ограниченной, если все её члены находятся между двумя фиксированными числами.

Определение

∃α,β∈R:∀n∈Nα≤xn​≤β. Равносильная запись: ∃M>0:∀n∈N∣xn​∣≤M.

  • α — нижняя граница.
  • β — верхняя граница.

🎯 4. Предел последовательности

Определение

Число a называется пределом последовательности, если её члены начиная с некоторого номера становятся сколь угодно близкими к a.

Определение через ε

limn→∞​xn​=a ∀ε>0∃N=N(ε)∈N:∀n≥N∣xn​−a∣<ε.

ε — допустимое отклонение от предела, N — номер, начиная с которого условие выполняется.

Доказательство предела из лекции

limn→∞​3n−12n+3​=32​.

Для произвольного ε>0 найдём подходящий номер N:

​3n−12n+3​−32​​=​3(3n−1)6n+9−6n+2​​=9n−311​<ε.

Поскольку n≥1, знаменатель положителен.

11<ε(9n−3) 9nε>11+3ε n>9ε11+3ε​.

Можно выбрать

N=⌊9ε11+3ε​⌋+1.

Проверка при ε=0,1

n>0,911+0,3​=9113​≈12,56. Следовательно, N=13. ∣x13​−2/3∣=11411​≈0,0965<0,1. При n=12 отклонение равно 11/105≈0,1048>0,1. Для всех n≥13 отклонение не больше 11/114.

🧮 5. Вычисление пределов

При отношении многочленов неопределённость вида ∞∞​ раскрывается делением числителя и знаменателя на подходящую степень n.

Пример 1

limn→∞​9n2−3n3+179n3+5n2−6n−2​.

Делим на n3:

limn→∞​n9​−3+n317​9+n5​−n26​−n32​​=−39​=−3​.

Пример 2

limn→∞​7n+57n4+5n3−4​.

limn→∞​n37+n5​7+n5​−n44​​=+∞.

Пример 3

limn→∞​8n5+7n2+17n5+8n3+4​.

limn→∞​8+n37​+n51​7+n28​+n54​​=87​​.

📊 6. Сводная таблица

Пусть Pm​(n) и Qk​(n) — многочлены степеней m и k, а am​ и bk​ — их ненулевые старшие коэффициенты.

УсловиеПредел Pm​(n)/Qk​(n)
m<k0
m=kam​/bk​
m>k, am​/bk​>0+∞
m>k, am​/bk​<0−∞

Главное правило

Сравнивай старшие степени и старшие коэффициенты. При n→+∞ все выражения 1/np при p>0 стремятся к нулю.

📖 Термины

  • 🔢 Последовательность — функция натурального аргумента.
  • 📈 Монотонность — сохранение направления изменения членов.
  • 📏 Ограниченность — наличие общей верхней и нижней границ.
  • 🎯 Предел — число, к которому члены последовательности становятся сколь угодно близкими.
  • ♾️ Сходимость — существование конечного предела.
  • ❓ Неопределённость — форма, по которой нельзя сразу установить предел.
