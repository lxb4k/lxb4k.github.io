📐 1. По общему уравнению

L1​:A1​x+B1​y+C1​=0L2​:A2​x+B2​y+C2​=0

Нормали: n1​(A1​;B1​), n2​(A2​;B2​).

Угол между прямыми равен углу между их нормалями: (L1​,L2​)​=(n1​,n2​)​.

🧮 Формула

cos(L1​,L2​​)=cos(n1​,n2​​)=∣n1​∣⋅∣n2​∣n1​⋅n2​​=A12​+B12​​A22​+B22​​A1​A2​+B1​B2​​

✅ Следствия: условия параллельности и перпендикулярности

УсловиеВыводФормула
L1​∥L2​n1​ и n2​ коллинеарныA2​A1​​=B2​B1​​
L1​⊥L2​n1​⊥n2​, то есть n1​⋅n2​=0A1​A2​+B1​B2​=0

📈 2. По угловым коэффициентам

L1​:y=k1​x+b1​L2​:y=k2​x+b2​

k1​=tgα1​k2​=tgα2​α=α2​−α1​

tgα=tg(α2​−α1​)

Используем формулу тангенса разности tg(x−y)=1+tgx⋅tgytgx−tgy​:

🧮 Формула

tgα=​1+k2​⋅k1​k2​−k1​​​

✅ Следствия

  1. Параллельность: L1​∥L2​⟺α=0∘ (или 180∘) ⟺tgα=0⇒k1​=k2​​
  2. Перпендикулярность: L1​⊥L2​⟺α=90∘⇒k1​⋅k2​=−1​

🧭 3. По каноническим уравнениям

L1​:l1​x−x1​​=m1​y−y1​​q​1​(l1​,m1​)

L2​:l2​x−x2​​=m2​y−y2​​q​2​(l2​,m2​)

Угол между прямыми равен углу между направляющими векторами: (L1​,L2​)​=(q​1​,q​2​)​.

🧮 Формула

cos(L1​,L2​​)=cos(q​1​,q​2​​)=∣q​1​∣⋅∣q​2​∣q​1​⋅q​2​​=l12​+m12​​l22​+m22​​l1​l2​+m1​m2​​

✅ Следствия

УсловиеВыводФормула
L1​∥L2​q​1​∥q​2​l2​l1​​=m2​m1​​
L1​⊥L2​q​1​⊥q​2​, q​1​⋅q​2​=0l1​l2​+m1​m2​=0

🔺 4. Задача про треугольник

Даны вершины треугольника: A(3;5), B(−2;1), C(1;−4).

Найти:

  1. уравнение медианы AM
  2. уравнение высоты BH
  3. уравнение прямой CC1​, параллельной AB
  4. cosA
  5. tgB

1️⃣ Медиана AM

M — середина BC:

M(2xB​+xC​​;2yB​+yC​​)=M(2−2+1​;21−4​)=M(−21​;−23​)

Прямая через две точки A и M:

AM:−21​−3x−3​=−23​−5y−5​⇒7x−3​=13y−5​

✅ AM:13x−7y−4=0

2️⃣ Высота BH (BH⊥AC)

Условие перпендикулярности: kAC​⋅kBH​=−1.

AC:1−3x−3​=−4−5y−5​⇒y=29​x−217​,kAC​=29​

kBH​=−92​(так как 29​⋅(−92​)=−1)

Уравнение через точку B: y−yB​=k(x−xB​):

y−1=−92​(x+2)

✅ BH:2x+9y−5=0

3️⃣ Прямая CC1​∥AB

Параллельные прямые имеют равные угловые коэффициенты: kCC1​​=kAB​.

AB:−2−3x−3​=1−5y−5​⇒y=54​x+513​,kAB​=54​=kCC1​​

Через точку C: y−yC​=kCC1​​(x−xC​):

y+4=54​(x−1)

✅ CC1​:4x−5y−24=0

4️⃣ cosA

cosA=cos(AC,AB​)=cos(nAC​,nAB​​). Нормали: из AC:9x−2y−17=0 получаем nAC​=(9;−2), из AB:4x−5y+13=0 получаем nAB​=(4;−5).

cosA=81+4​⋅16+25​9⋅4+(−2)(−5)​=85​⋅41​46​

5️⃣ tgB

tgB=tg(AB,BC​)=​1+kAB​⋅kBC​kAB​−kBC​​​.

BC:xC​−xB​x−xB​​=yC​−yB​y−yB​​⇒3x+2​=−5y−1​⇒y=−35​x−37​,kBC​=−35​

tgB=​1+54​⋅(−35​)54​+35​​​=​−31​1537​​​=537​

🧊 5. Уравнение плоскости в пространстве

Плоскость Π проходит через M0​(x0​,y0​,z0​) перпендикулярно вектору нормали n(A,B,C). Произвольная точка плоскости M(x,y,z).

M0​M​=(x−x0​,y−y0​,z−z0​)

Так как n⊥Π, то n⊥M0​M​ и n⋅M0​M​=0:

A(x−x0​)+B(y−y0​)+C(z−z0​)=0

Ax+By+CzD−Ax0​−By0​−Cz0​​​=0

🧮 Общее уравнение плоскости

Π:Ax+By+Cz+D=0,n(A;B;C)

🔗 Аналогия с прямой

Уравнение плоскости получается точно так же, как общее уравнение прямой на плоскости: через вектор нормали и скалярное произведение, только с третьей координатой z.
