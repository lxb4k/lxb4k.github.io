🔲 1. Минор

Пусть дана матрица третьего порядка:

A=​a11​a21​a31​​a12​a22​a32​​a13​a23​a33​​​

📌 Определение

Минором Mij​ матрицы A к элементу aij​ называется определитель, который получается вычёркиванием i-й строки и j-го столбца.

Пример. Для M23​ вычёркиваем 2-ю строку и 3-й столбец:

M23​=​a11​a31​​a12​a32​​​

➕ 2. Алгебраическое дополнение

🧮 Формула

Алгебраическое дополнение Aij​ к элементу aij​: Aij​=(−1)i+jMij​

Знак зависит от суммы номеров строки и столбца — «шахматка» знаков:

​+−+​−+−​+−+​​

  • Если i+j чётно ➜ знак + (Aij​=Mij​)
  • Если i+j нечётно ➜ знак − (Aij​=−Mij​)

📐 3. Разложение определителя

Вычисление определителей разложением по строкам и столбцам.

🎓 Теорема

Определитель матрицы равен сумме произведений элементов строки (столбца) на соответствующие им алгебраические дополнения.

Разложение по 3-й строке

∣A∣=a31​A31​+a32​A32​+a33​A33​

Раскрываем алгебраические дополнения:

∣A∣=a31​(−1)3+1​a12​a22​​a13​a23​​​+a32​(−1)3+2​a11​a21​​a13​a23​​​+a33​(−1)3+3​a11​a21​​a12​a22​​​

Считаем определители 2×2:

∣A∣=a31​(a12​a23​−a22​a13​)−a32​(a11​a23​−a21​a13​)+a33​(a11​a22​−a12​a21​)

✅ Итоговая формула определителя 3×3

∣A∣=a11​a22​a33​+a12​a23​a31​+a13​a21​a32​−a13​a22​a31​−a11​a23​a32​−a12​a21​a33​ Это правило треугольников (Саррюса), получившееся из разложения.

💡 Как выбирать строку

Раскладывать удобнее по строке или столбцу, где больше нулей: слагаемые с нулевым элементом отпадают.

✏️ 4. Пример: вычислить определитель

​146​253​301​​

Разложение по 2-му столбцу (элементы 2, 5, 3):

=2⋅(−1)1+2​46​01​​+5⋅(−1)2+2​16​31​​+3⋅(−1)3+2​14​30​​

=−2⋅4+5⋅(1−18)−3⋅(0−12)=−8−85+36=−57

⚠️ Проверь итог в тетради

В тетради этот пример записан с другим итогом: слагаемые −8, −85 и третье сходятся с моим расчётом только по первым двум. Верный ответ, который получается и по правилу треугольников, и по разложению: −57.

🔄 5. Обратная матрица

📌 Определение

Матрица A−1 называется обратной к матрице A, если A−1⋅A=A⋅A−1=E где E — единичная матрица.

Формула для матрицы 3-го порядка

🧮

A−1=∣A∣1​​A11​A12​A13​​A21​A22​A23​​A31​A32​A33​​​

  • Матрица из алгебраических дополнений транспонирована: Aij​ ставится на место (j,i) (обратите внимание на порядок индексов в строках)
  • Обратная матрица существует только если ∣A∣=0

Алгоритм

  1. Найти ∣A∣ (если 0 ➜ обратной нет)
  2. Найти все 9 алгебраических дополнений Aij​
  3. Составить матрицу из них и транспонировать
  4. Умножить на ∣A∣1​
  5. Проверить: A−1⋅A=E

✏️ 7. Правило Крамера

Рассмотрим систему трёх уравнений с тремя неизвестными:

⎩⎨⎧​a11​x+a12​y+a13​z=b1​a21​x+a22​y+a23​z=b2​a31​x+a32​y+a33​z=b3​​

Определители

Главный определитель — из коэффициентов при неизвестных:

Δ=∣A∣=​a11​a21​a31​​a12​a22​a32​​a13​a23​a33​​​

Вспомогательные — в главном определителе столбец при неизвестной заменяется столбцом свободных членов b:

Δx​=​b1​b2​b3​​a12​a22​a32​​a13​a23​a33​​​Δy​=​a11​a21​a31​​b1​b2​b3​​a13​a23​a33​​​Δz​=​a11​a21​a31​​a12​a22​a32​​b1​b2​b3​​​

🧮 Формулы Крамера

x=ΔΔx​​y=ΔΔy​​z=ΔΔz​​ Работает только при Δ=0.

Пример

⎩⎨⎧​3x+2y+z=5x+y−z=04x−y+5z=3​

Главный определитель (разложение по 1-му столбцу):

Δ=​314​21−1​1−15​​=3​1−1​−15​​−1​2−1​15​​+4​21​1−1​​=12−11−12=−11

Δx​ (1-й столбец заменён на (5,0,3)):

Δx​=​503​21−1​1−15​​=5​1−1​−15​​+3​21​1−1​​=20−9=11

Δy​ (2-й столбец заменён на (5,0,3)):

Δy​=​314​503​1−15​​=−33

Δz​ (3-й столбец заменён на (5,0,3)):

Δz​=​314​21−1​503​​=−22

Решение:

x=−1111​=−1y=−11−33​=3z=−11−22​=2

✅ Проверка подстановкой

  • 3⋅(−1)+2⋅3+2=5 ✓
  • −1+3−2=0 ✓
  • 4⋅(−1)−3+5⋅2=3 ✓

Ответ: (x,y,z)=(−1,3,2)

🧮 8. Матричный метод

Решение системы уравнений с помощью обратной матрицы.

Обозначим:

A=​a11​a21​a31​​a12​a22​a32​​a13​a23​a33​​​X=​xyz​​B=​b1​b2​b3​​​

Система записывается как матричное уравнение A⋅X=B.

Умножаем обе части слева на A−1:

A−1AX=A−1B

E⋅X=A−1B⟹X=A−1B​

⚠️ Порядок умножения

Матрицы не коммутативны: A−1 умножаем на B слева, то есть A−1B, а не BA−1.
