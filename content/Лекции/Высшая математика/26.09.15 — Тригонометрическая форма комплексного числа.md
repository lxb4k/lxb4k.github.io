$$z = \rho (\cos\varphi + i\sin\varphi)$$

Связь с алгебраической формой:
$$\begin{cases} a = \rho \cos\varphi \\ b = \rho \sin\varphi \end{cases} \implies \begin{cases} \rho = \sqrt{a^2 + b^2} \\ \varphi = \operatorname{arctg}\frac{b}{a} \end{cases}$$

* $\rho$ — **модуль** комплексного числа ($\rho \ge 0$).
* $\varphi$ — **главное значение аргумента** комплексного числа: $\varphi = \operatorname{arg} z \in (-\pi; \pi]$.
* Полный аргумент: $\operatorname{Arg} z = \operatorname{arg} z + 2\pi k, \quad k \in \mathbb{Z}$.

> [!tip] Поправка аргумента на четверть
> * **I четверть** ($a>0, b>0$): $\varphi = \operatorname{arctg}\left|\frac{b}{a}\right|$
> * **II четверть** ($a<0, b>0$): $\varphi = \pi - \operatorname{arctg}\left|\frac{b}{a}\right|$
> * **III четверть** ($a<0, b<0$): $\varphi = -\pi + \operatorname{arctg}\left|\frac{b}{a}\right|$
> * **IV четверть** ($a>0, b<0$): $\varphi = -\operatorname{arctg}\left|\frac{b}{a}\right|$

### Примеры перевода в тригонометрическую форму

1. $z = 1 + i$  
   $\rho = \sqrt{1^2 + 1^2} = \sqrt{2}$, $\varphi = \operatorname{arctg}(1) = \frac{\pi}{4}$  
   $$z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$$

2. $z = \sqrt{3} - i$  
   $\rho = \sqrt{3 + 1} = 2$, $\varphi = \operatorname{arctg}\left(-\frac{1}{\sqrt{3}}\right) = -\frac{\pi}{6}$  
   $$z = 2\left(\cos\left(-\frac{\pi}{6}\right) + i\sin\left(-\frac{\pi}{6}\right)\right)$$

3. $z = -1 - \sqrt{3}i$  
   $\rho = \sqrt{1 + 3} = 2$, $\varphi = \operatorname{arctg}(\sqrt{3}) - \pi = \frac{\pi}{3} - \pi = -\frac{2\pi}{3}$  
   $$z = 2\left(\cos\left(-\frac{2\pi}{3}\right) + i\sin\left(-\frac{2\pi}{3}\right)\right)$$

4. $z = -2 + 2i$  
   $\rho = \sqrt{4 + 4} = \sqrt{8} = 2\sqrt{2}$, $\varphi = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$  
   $$z = 2\sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)$$

### Умножение и возведение в степень

Пусть $z_1 = \rho_1(\cos\varphi_1 + i\sin\varphi_1)$ и $z_2 = \rho_2(\cos\varphi_2 + i\sin\varphi_2)$:

$$z_1 \cdot z_2 = \rho_1 \rho_2 \left(\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\right)$$

> [!note] 
> При умножении комплексных чисел их модули перемножаются, а аргументы складываются.

#### Формула Муавра:
$$z^n = \rho^n (\cos(n\varphi) + i\sin(n\varphi))$$

**Пример:** Найти $z^{73}$ для $z = -3 - 3i$.
* $\rho = \sqrt{9 + 9} = 3\sqrt{2}$
* $\varphi = \operatorname{arctg}(1) - \pi = -\frac{3\pi}{4}$
* $z^{73} = (3\sqrt{2})^{73} \left(\cos\left(-73 \cdot \frac{3\pi}{4}\right) + i\sin\left(-73 \cdot \frac{3\pi}{4}\right)\right)$
* $-\frac{219\pi}{4} = -54\pi - \frac{3\pi}{4} \equiv -\frac{3\pi}{4} \pmod{2\pi}$
* В результате: $z^{73} = -3^{73} \cdot 2^{36} (1 + i)$

### Извлечение корня $n$-й степени

$$\sqrt[n]{z} = \sqrt[n]{\rho} \left(\cos \frac{\varphi + 2\pi k}{n} + i\sin \frac{\varphi + 2\pi k}{n}\right), \quad k = 0, 1, \dots, n-1$$

**Пример:** Найти $\sqrt[3]{z}$ для $z = -\sqrt{3} + i$.
* $\rho = \sqrt{3 + 1} = 2$, $\varphi = \frac{5\pi}{6}$ (II четверть)
* $z = 2\left(\cos\frac{5\pi}{6} + i\sin\frac{5\pi}{6}\right)$
* $\sqrt[3]{z} = \sqrt[3]{2} \left(\cos \frac{\frac{5\pi}{6} + 2\pi k}{3} + i\sin \frac{\frac{5\pi}{6} + 2\pi k}{3}\right)$

Корни:
* $k=0 \implies \sqrt[3]{2} \left(\cos\frac{5\pi}{18} + i\sin\frac{5\pi}{18}\right)$
* $k=1 \implies \sqrt[3]{2} \left(\cos\frac{17\pi}{18} + i\sin\frac{17\pi}{18}\right)$
* $k=2 \implies \sqrt[3]{2} \left(\cos\frac{29\pi}{18} + i\sin\frac{29\pi}{18}\right)$
